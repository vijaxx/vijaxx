#### What I've built

- **[redditreels](https://github.com/vijaxx/redditreels)** — an unattended pipeline that sources a story, rewrites it with an LLM, generates voiceover, renders a captioned vertical video, and publishes it across YouTube/Facebook/Rumble, then feeds performance data back into what it does next.
- **[pinforge](https://github.com/vijaxx/pinforge)** — turns a product theme into a full listing: a print-ready PDF, a set of Pinterest pin creatives, SEO copy, and posts it, with a SQLite layer to track how it performs.
- **[kdp-puzzle-engine](https://github.com/vijaxx/kdp-puzzle-engine)** — generates print-ready puzzle books (word search, Sudoku, mazes) end to end, with an unattended factory mode and a compliance check that runs before anything reaches upload.

Each of these runs as scheduled, unattended jobs — not one-off scripts. A recurring theme across all three: browser automation over the Chrome DevTools Protocol for the platforms without a workable API, and free-tier LLM APIs (Gemini/Groq) wired in through a small compatibility shim so the pipeline doesn't depend on a paid key to run.
